# Jogo da Velha

Um jogo da velha desenvolvido em HTML, CSS e JavaScript, com duas opções de jogo:

- 2 jogadores
- Contra IA

O projeto foi realizado como parte de um curso de JavaScript, com foco em lógica de programação, manipulação do DOM e interação com elementos da interface.

## 🎮 Funcionalidades

- Tabuleiro interativo do jogo da velha
- Escolha entre jogar com outro jogador ou contra a IA
- Sistema de placar para acompanhar os pontos
- Mensagens de vitória e empate
- Reinício da partida após o fim da rodada
- Interface simples e visualmente clara

## 🧠 Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript

## 📁 Estrutura do projeto

```text
Jogo-da-Velha/
├── assets/
│   ├── jogo.css
│   └── jogo.js
├── index.html
├── LICENSE
├── README.md
└── .vscode/
```

### Descrição dos arquivos

- `index.html`: estrutura principal da página e elementos do jogo
- `assets/jogo.css`: estilos do tabuleiro, botões, placar e mensagens
- `assets/jogo.js`: lógica do jogo, turno dos jogadores, verificação de vencedor e IA
- `LICENSE`: licença do projeto
- `README.md`: documentação do repositório

## ▶️ Como executar

1. Clone o repositório:

```bash
git clone https://github.com/RichardWSPereira/Jogo-da-Velha.git
```

2. Acesse a pasta do projeto:

```bash
cd Jogo-da-Velha
```

3. Abra o arquivo `index.html` no navegador.

Você também pode usar uma extensão como Live Server para rodar a página com melhor experiência no desenvolvimento.

## 🕹️ Como jogar

- Escolha o modo desejado na tela inicial:
  - `2 Jogadores`
  - `Contra IA`
- Clique em uma casa do tabuleiro para realizar a jogada.
- O primeiro a alinhar 3 símbolos na horizontal, vertical ou diagonal vence a rodada.
- Quando a partida terminar, o placar é atualizado e uma nova rodada pode começar automaticamente.
